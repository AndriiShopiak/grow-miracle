🔍 Перевірка Schema.org розмітки для "Хурмовий сад"

📋 Інструкції для перевірки:

  1. Локальна перевірка: Відкрийте http://localhost:3000
  2. Перевірка продукту: Відкрийте http://localhost:3000/products/1
  3. Перевірка галереї: Відкрийте http://localhost:3000/gallery

🛠️ Онлайн інструменти для перевірки:

1. Google Rich Results Test:

Перейдіть на https://search.google.com/test/rich-results

Вставте URL: http://localhost:3000/products/1

2. Schema.org Validator:

Перейдіть на https://validator.schema.org/

3. Facebook Sharing Debugger:

Перейдіть на https://developers.facebook.com/tools/debug/

📊 Що має показувати Google Rich Results Test:

  • ✅ Product - розпізнавання продукту
  • ✅ LocalBusiness - розпізнавання бізнесу
  • ✅ WebSite - розпізнавання сайту
  • ✅ ImageGallery - розпізнавання галереї

🔍 Як перевірити в браузері:

  1. Відкрийте сторінку продукту
  2. Натисніть F12 (Developer Tools)
  3. Перейдіть на вкладку Elements
  4. Знайдіть тег <script type="application/ld+json">
  5. Скопіюйте JSON і вставте в Schema.org Validator

✅ Очікувані результати:

Для продукту (products/1):

{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Соснівська",
  "description": "хурма гібридна - солодкий, соковитий...",
  "image": "https://sad-olega.com/products/1.jpg",
  "offers": {
    "@type": "Offer",
    "price": "800",
    "priceCurrency": "UAH"
  }
}

🚀 Наступні кроки після перевірки:

  1. Задеплоїть сайт на хостинг
  2. Додайте сайт в Google Search Console
  3. Відправте sitemap.xml в Google
  4. Зачекайте 1-2 тижні на індексацію
  5. Перевірте результати в пошуку
